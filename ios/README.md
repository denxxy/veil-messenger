# Veil для iPhone

iOS-версия на том же протоколе, что macOS- и Windows-клиенты: переписка
между любыми клиентами через общий relay работает «из коробки». Ядро
(криптография, транспорт, хранилище) — общие файлы с macOS-приложения
(`../macos/Veil/Sources/`), интерфейс — телефонный SwiftUI
(`ios/VeilIOS/ViewsIOS.swift`, iOS 16+).

## Сборка на iPhone

Требуется Mac с полным Xcode 14+ (с этой машины стоит только Command Line
Tools — проекта Xcode там нет, поэтому финальная сборка делается у вас).

1. Откройте `ios/VeilIOS.xcodeproj` в Xcode.
2. Выберите таргет **Veil** → вкладка *Signing & Capabilities*:
   - Team: ваш Apple ID (можно бесплатный: Xcode → Settings → Accounts →
     добавить Apple ID);
   - при необходимости поправьте Bundle Identifier на уникальный
     (например `chat.veil.ios.ВАШ_НИК`).
3. Подключите iPhone кабелем, выберите его как устройство запуска и
   нажмите **Run** (⌘R).
4. На iPhone: Настройки → Основные → VPN и управление устройством →
   доверять своему Apple ID-разработчику (для бесплатных аккаунтов).

Нюансы бесплатного Apple ID: приложение подписывается на 7 дней — потом
нужно повторно подключить iPhone и нажать Run; до 3 приложений одновременно.
Платный аккаунт Developer Program ($99/год) даёт подписку на год.

Сборка для симулятора: в Xcode выберите любой iPhone-симулятор и ⌘R —
подпись не нужна.

## Проверка без Xcode

`bash ios/build_check.sh` компилирует и запускает UI на macOS — тот же
код (iOS-специфика изолирована в `#if canImport(UIKit)`-хелперах).
Ошибки этой проверки = ошибки iOS-сборки.

## Использование

Как в остальных клиентах: «Создать личность» → «Реле-серверы» → добавить
`https://relay.example.com:8443` → «Мой профиль» → «Поделиться
приглашением» / «Скопировать код» → собеседник вставляет его в
«Добавить контакт». Импорт резервной копии личности (в т.ч. файла из
macOS/Windows) — «Импортировать…».

## Ограничения iOS-версии (v0.1)

- Доставка работает в активном и фоновом (в течение нескольких минут)
  состоянии; при заморозке приложения системой сообщения подтянутся при
  следующем открытии. Push-уведомления и фоновая выборка (BGTaskScheduler/
  APNs-самописный relay) — в дорожной карте.
- Ключи хранятся в песочнице приложения (`store.json`); после удаления
  приложения личность теряется — сохраняйте экспорт.

## Регенерация проекта

Проект сгенерирован [XcodeGen](https://github.com/yonaskolb/XcodeGen)
из `ios/project.yml`. При изменении списка файлов:

```bash
brew install xcodegen && cd ios && xcodegen generate
```

Сгенерированный `VeilIOS.xcodeproj` закоммичен, чтобы проект открывался
без установки XcodeGen.
